# Rachel Hveem Therapy

Astro marketing site for Rachel Hveem Therapy.

## Local development

```sh
npm install
npm run dev
```

Run `npm run check` for Astro/type checks and `npm run build` for the production build.

Before launch, replace the temporary form recipient (`hello@example.com`) with the practice's secure appointment workflow or scheduling provider. Do not collect private health information through a standard `mailto:` form.
